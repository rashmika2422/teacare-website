=========================================================
TEACARE EVENTS PVT. LTD. - WEBSITE MAINTENANCE GUIDE
=========================================================
Hello! This guide is written for beginners. It explains exactly how to change text, update images, and maintain your website without breaking anything. 

Your website is built using "Next.js" (a React framework). This means your website is split into small, manageable pieces called "Components".

---------------------------------------------------------
PART 1: HOW TO CHANGE TEXT ANYWHERE ON THE WEBSITE
---------------------------------------------------------
To change text, you just need to find the correct file, delete the old text, and type the new text. 

STEP 1: FIND THE RIGHT FILE
Look at the list below to find which file controls the part of the website you want to edit:

▶ For the MAIN HOME PAGE:
- The very top text with the typing animation: open `components/Hero.tsx`
- The short "Who We Are" summary: open `components/About.tsx`
- The Statistics (like 150+ Events): open `components/Experience.tsx`
- The Services (like Executive High Tea): open `components/Services.tsx`
- The Photo Gallery section: open `components/Gallery.tsx`
- The Interactive Event Planner (Calculator): open `components/Estimator.tsx`
- The Client Reviews: open `components/Testimonials.tsx`
- The bottom of the page (Footer & Social Links): open `components/Footer.tsx`

▶ For the OTHER PAGES:
- The dedicated "About Us" Page: open `app/about/page.tsx`
- The dedicated "Contact Us" Page: open `app/contact/page.tsx`

STEP 2: EDIT THE TEXT
1. Open the file in your code editor (like Visual Studio Code).
2. Press [Ctrl + F] on Windows or [Cmd + F] on Mac to search.
3. Type the exact word or sentence you want to change to find it quickly.
4. Carefully delete the old text and type the new text.

⚠ GOLDEN RULES FOR EDITING TEXT ⚠
- Rule 1: DO NOT delete the HTML tags around the text. 
  (Example: Only change the word inside <p>Old Text</p> to <p>New Text</p>)
- Rule 2: If you want to use an apostrophe (like the word "Don't" or "Teacare's"), you should type it like this: Teacare&apos;s  OR you must put double quotes around the whole sentence.
- Rule 3: Save your file ([Ctrl + S] or [Cmd + S]) to see the changes.


---------------------------------------------------------
PART 2: HOW TO CHANGE IMAGES ANYWHERE ON THE WEBSITE
---------------------------------------------------------
Changing an image involves adding your new photo to the project folder and typing its name into the code.

STEP 1: ADD YOUR NEW PHOTO TO THE FOLDER
1. Find your new photo on your computer (e.g., `my-new-photo.jpg`).
2. Copy it into this specific folder in your project: 
   `public/assets/images/`

STEP 2: UPDATE THE CODE TO USE THE NEW PHOTO
1. Open the file that controls the section you want to change (use the list from Part 1).
2. Search for the word `.JPG` or `.PNG` or `.MP4` to find where the old image is linked.
3. You will see a line of code that looks like this:
   backgroundImage: "url('/assets/images/old-photo-name.JPG')"
   OR
   <img src="/assets/images/old-photo-name.JPG" />
4. Carefully delete ONLY the old file name, and type your new file name.
   It should now look like this:
   backgroundImage: "url('/assets/images/my-new-photo.jpg')"
5. Save the file.


---------------------------------------------------------
PART 3: HOW TO MAINTAIN AND RUN THE WEBSITE
---------------------------------------------------------
If you close your computer and need to start working on the website again, follow these steps:

STEP 1: START THE DEVELOPMENT SERVER
1. Open your code editor (Visual Studio Code).
2. Open the Terminal inside the editor (Click "Terminal" > "New Terminal" at the top).
3. Type this exact command and press Enter:
   npm run dev
4. Wait a few seconds until it says "Ready".
5. Open your web browser (Chrome, Safari, etc.) and go to:
   http://localhost:3000
   
Now, every time you save a file, the browser will automatically refresh to show your changes!

STEP 2: ADDING NEW STYLES OR COLORS
If you want to change the deep gray backgrounds or golden-orange colors, all of those main styles are located in one master file:
- Open `app/globals.css`
- Do not edit this file unless you are comfortable with CSS.
